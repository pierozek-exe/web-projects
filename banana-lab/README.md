# Banana Lab

Strona o bananach w stylu neumorfizmu: interaktywny miernik dojrzałości (etapy 1–7), wartości odżywcze, ciekawostki i historia Gros Michel vs Cavendish.

Jeden plik `index.html`, bez frameworków i bez budowania.

## Uruchomienie

Otwórz `index.html` w przeglądarce albo zobacz wersję online na GitHub Pages.
